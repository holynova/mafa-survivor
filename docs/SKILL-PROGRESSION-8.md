# 33个技能的1—8级成长方案（讨论稿）

> 状态：仅设计，尚未实现。此文不修改现行GDD、运行规则、存档或已发布版本。数值为首轮建议，不能视为已经通过平衡测试。

> 后续建议：结合单局升级预算，现更推荐6级上限，详见[构筑目标与6级方案](RUN-BUILD-AND-SKILL-LEVELS.md)。本页保留为首轮8级备选稿；后续六级方案已在alpha.26实施，八级方案未实施。

## 1. 现在游戏实际上如何升级

当前33个技能最高均为3级。学到技能为1级；升至2级、3级时，各从该技能的强化分支中选一项。同一分支可以重复选择，只有选中的字段增加；升等级本身不会自动增加全部属性。

例如火球术的分支是伤害+22%、独立目标+1、弹速+30%。如果2级和3级都选数量，最多变为3发；若两次都选伤害，仍然只有1发。它目前没有固定的“3级加一发、6级再加一发”。

依据：[技能定义](../src/spells.ts)、[升级生成与应用](../src/game.ts)、[当前3级规则](GDD.md)。文末保留全部现行分支便于比较。

## 2. 建议采用的成长规则

- 改成固定1—8级成长：升级仍然选择培养哪个技能，但同一个技能每一级给什么收益固定，方便理解和验证。六个技能槽与独立普攻保持现有结构。
- 表中1级是基础状态；2—8级写的是“本级新获得的变化”，之前获得的效果保留。写“→”的数值是升级后的总值，不要再叠加。
- 威力、治疗、生命、半径、弹速等“+X%”均相对该技能1级基础值相加，不逐级复利。例如火球2级+12%、7级再+12%，8级单发威力总计为基础的124%。概率增长明确写“个百分点”。
- “CD−X%”是相对1级技能CD增加的本技能冷却缩减。两次−8%、−7%合计−15%，再与角色全局冷却缩减相乘，最后应用技能冷却下限。召唤攻击间隔与召唤CD分开计算。
- 1级基础伤害、道术／魔法／攻击的成长沿用现行公式；表中不把角色等级或装备带来的提升误记为技能升级收益。伤害增强作用于该技能对应的伤害项；攻杀、烈火只增强其附加伤害项，不放大整次普攻。
- 3级、6级通常安排数量、形状或触发条件变化；5级给部分技能定位变化；8级给最终强化。辅助技能以持续、覆盖、触发条件为主，不强行给伤害或增加召唤数量。

### 数量与射程的统一解释

火球、大火球、火符和雷电的数量都是“每次施放最多攻击几个不同的合格敌人”。场上只有一个合格目标时只攻击它一次；不会把四发火球全部叠到同一个Boss。目标不足时不生成没有目标的假投射物。

侦测距离继续作为可升级的全局属性，建议保留基础300px、上限450px。定点施法落点和索敌距离受侦测范围限制；直线技能实际伤害长度取形状上限与侦测距离的较小值。范围技能可以覆盖落点周围，但不搜索全屏目标。特效长度和实际命中边界必须一致。

“格”按现有战斗尺度48px换算，不直接等同于地图素材的地砖宽度。表中半径指命中半径，宽度指完整横向宽度，神兽张角指完整扇形夹角。

**法师规则补充**

- 火球定位为快速多目标；大火球定位为单发重击，仍不附带爆炸；雷电保留瞬发与精英／Boss优先。冰咆哮是大范围冰伤，本方案不增加减速或冻结。
- 火墙3级、6级增加的是实际每次铺火数量，同时提高存量上限；这与当前只增加存量上限的分支不同。优先在敌群路径上的不同位置铺设，找不到有效位置时不硬凑数量。达到上限时替换最旧火墙，同一目标只承受一份火墙持续伤害。
- 魔法盾最终技能减伤35%、持续7秒；冷却至少8秒，保留至少1秒空窗；角色全部来源综合减伤仍不得超过65%。
- 抗拒火环无伤害，Boss／精英免疫击退；等级不合格的普通怪也不能推开。地狱火是一次直线火焰，不变成火墙；疾光电影每个目标每次只命中一次。
- 地狱雷光由至少4敌，逐步降到3敌、2敌触发，增强实用性；单独一个Boss仍不触发，避免替代单体雷电。
- 圣言普通亡灵成功率基础35%，再计敌我等级差；8级技能提供合计10个百分点成功率，最终限制10%—90%。合格精英／Boss只受普通伤害、单次上限15%最大生命，永不被秒杀；不合格种类不会因升级而变成合格目标。
- 诱惑仅能招合格普通怪，不能招Boss／精英。8级最多5只诱惑宝宝；成功率最终仍限制10%—85%。增加上限不等于升级瞬间凭空生成宝宝。
- 瞬息移动的“落点优选概率”指从合法候选落点中优先挑更安全区域的概率，不是成功传送概率。所有实际落点都必须可站立、可连通；最小距离无合法解时不传送、不消耗CD；不附带无敌。

## 7. 升级预算与实现验收（后续工作，不是已完成）

### 升级预算

把上限从3提高到8会明显增加培养成本，不能只把rank上限改成8就宣称完成。六个技能全部8级，已有一个1级起始技能时，共需47次技能相关选择（5次新学+42次升级），还未计通用属性。通常一局不应保证六个技能全满。

首轮建议的成型目标是2个8级核心技能，其他技能分配在2—3级。示例8／8／3／3／2／2，需要25次技能选择，若每次角色升级只给1次选择且全用于技能，对应至少角色26级。此例是点数预算，不是对当前15分钟流程等级的保证。实施前需核查经验曲线、普通属性选择占比与技能候选规则，再确定是否需要独立技能点或调整经验；本讨论稿不预先改经验掉落或关卡时长。

### 后续界面与测试要求

1. 技能详情展示1—8级完整列表，当前级高亮；升级卡显示“当前→升级后”实际数值，如“火球2级→3级：投射物1→2”，而不是只写“技能强化”。
2. 测试模式可直接选择任意技能与1—8级，显示实际CD、数量、半径、命中边界；可切换裸装与满属性，确保封顶后不会出现升级卡承诺不存在的效果。
3. 数量节点逐级做截图／短录屏：火球3／6／8、大火球4／8、火符3／6、火墙3／6、骷髅5、神兽3／5／7／8。每个等级还应有可离线验证的实际效果数据。
4. 用单Boss、四个分散敌人、密集群怪、墙边、友方受伤五类固定场景检查：不能重复命中同Boss、隔墙索敌、叠火墙伤害，治疗不能溢出，隐身不能永久覆盖，喷火不能只有画面无伤害。
5. 旧存档不能直接把原分支数值与新固定成长相加。应备份原数据，按技能当前等级重建新效果，并提供迁移说明；随机数、检查点、测试工具与UI的等级上限要同步处理。
6. 平衡验证分别看单体输出、群体输出、有效回血、召唤存活和技能点成本。现有三职业平衡尚未通过，不以“CD更短”或单职业通关作为八级设计平衡的证据。完成一阶段的实现及截图验证后，再按现有用户要求发布对应版本。

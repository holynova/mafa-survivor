# 真实战斗模拟与阶段记录

## 运行方式

```sh
npm run simulate -- --seeds=176,17,991 --maps=biche,mine,woma,zuma --classes=wizard,warrior,taoist --mode=normal --out=.artifacts/simulation.json
```

- 使用真实Game、原地图通行夹具和1/60秒步进；升级、替换、购买、刷新与下一波均走实际接口。进入章节前提供已解锁的测试档，不赋予战斗属性。
- 控制器只提供移动输入和玩家可执行的选择，不写生命、时钟、敌人血量、掉落或胜负；正常／试玩均关闭测试无敌。
- JSON保留策略SHA、来源提交／脏状态、地图源SHA、逐波等级／收入、购买数、伤害与停滞、Boss剩余HP和完整终态。遇到越界或经济／数量上限异常会报告failure并以失败退出。
- 当前策略为启发式走位，不代表普通玩家或GDD的熟练／新手统计模型。伤害、金币与HP使用真实随机种子；不能把这一小样本当作人类通关率、10k种子矩阵或性能验收。

## 修复及验收边界

1. 控制器先有自己的红色回归：原来用0.65秒预测位置，会越过近处导航节点而站住；改为实际10步输入窗口，并允许沿节点精确减速。tests/simulation.test.ts在修复前输出expected 0 to be greater than 0，修复后移动和同种子复现通过。
2. tests/combat-fairness.test.ts六项在游戏修复前均失败：旧远程怪先发弹、Boss预警内提前移动、召唤CD为15／8秒、攻击切到另一近邻。修复后同一命令六项全部通过。
3. 所有远程敌人共享0.7秒锁点预警；蜘蛛160px/s，其他敌弹180px/s。身体／阴影与弹体继续用已登记原图。
4. 骷髅精灵为0.8秒预警＋0.6秒飞行，锁定合法落点，落地后0.6秒恢复；可跳过墙体，落点必须在连通的可站立地面。原影子留在地面，身体抬升表现飞行。
5. 四Boss援军批次间隔统一20秒，源地图合法位置刷出；援军不掉经验／金币／装备。旧骷髅精灵召唤墙内稻草人的真实模拟异常已由该入口修复，后续36局未再出现。
6. 矿洞／沃玛／祖玛使用1.7／2.8／3.8压力系数，首波21／13／10只；比奇仍35只。单次金币面额为7／11／15，比奇4，概率和拾取倍率规则不变；怪物基础HP／伤害保持GDD值。
7. 正常精英按4／7／10／12波、试玩按第2波中段投放。沃玛勇士与半兽勇士属于原生精英，退出普通随机群。战士首次升级提供半月，道士提供骷髅，之后提供刺杀／施毒；用户仍可选其他强化。

还需：更多独立种子和构筑、合理的新手／熟练输入模型、战士输出与Boss接敌、矿洞／祖玛通关、后期经济曲线、真实长局和300敌人P95。当前固定种子模拟可用于查故障与比较规则，不能替代这些验收。

## alpha.11 武器成长与购买策略隔离

可用 `npm run simulate -- --seeds=176,17,991 --trace=shops --out=.artifacts/simulation.json` 记录每轮实际库存、价格、金币、持有武器及购买／锁定／解锁／刷新动作。关闭trace不改变决策。schemaVersion=2，策略名fixed-step-kiting-v5-budget；策略SHA现在按文件名、NUL分隔与内容合并src/simulation.ts及src/equipment.ts，同时列出各文件SHA。旧V4仅哈希simulation.ts，不能直接把两种口径当成同策略。

V5移动逻辑不变。商店先解除已过时的武器预约，HP低于40%且买得起时优先急救；遇到实际可见主属性升级武器，买不起则锁定并保留金币，买得起按真实接口购买；不会预测收入、免费给装备或改变HP／胜负。其他购买仍用启发式评分。这只改变离线控制器，浏览器测试模式的自动走位仍需手动升级和购物。

# 全技能排查 · alpha.39 · 2026-11-16

针对新版生存模式中「学了技能但不释放／看不到效果」进行逻辑与实机双重检查。原版规则由既有测试保护；不是无条件让所有技能按冷却空放。

## 确认问题与修复

1. 隐身需要静止、低血量且两名近敌，移动或同帧自动火符/普攻立即显形；渲染器也没有读取隐身状态。新版改为低血量且一个近敌即可施放，允许移动和自动攻击，身体/武器/宝宝透明度0.4；到期结束，普通怪贴身、精英及首领仍能侦测。
2. 集体隐身要求有静止宝宝，且隐身宝宝停止选敌。新版允许自身独立受益，160px内有敌人触发，宝宝可继续移动攻击；施法范围/持续时间/冷却保持成长表设定。
3. 群体治疗不是缺失资源，而是单人时只在35%以下生命触发。新版提高到70%，5级提高到80%；两名友方受伤时依然可群疗，满血不空放、不消耗冷却。
4. 瞬息移动默认 automaticTeleport=false，新版没有开启它的操作入口。新版自动在生命低于30%且90px内有敌人时触发；安全落点、距离和冷却约束保留。
5. 施法光效留在施放坐标，跑动后会离开角色；部分0.8秒特效按10fps只能播放前8帧。治疗/防御/隐身光效绑定受术者、10帧完整播放。通用特效和弹道另补高坐标层级防护；现有裁剪地图高度1536，高坐标问题仅作单测防护，不冒称在线复现。

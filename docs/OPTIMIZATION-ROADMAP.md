# 最佳实践优化实施进度

用户于2026-11-17授权按审查报告逐步优化。原版素材、全地图测试入口、主动删除/替换技能及旧版回退保持；每阶段分别验证和发布。完整目标见SURVIVOR-BEST-PRACTICES-AUDIT.md。

## 阶段1：可靠性与资源基线（alpha.41/42已发布，继续完善）
- 已实现：跨关未引用lazy图集回收，回收前断开隐藏对象池中的纹理引用，保留当前地图/敌人/装备/尸体所需资源；回收后允许重新加载。
- 已实现：存档删除重复JSON克隆，由schema校验产生独立快照；记录本地快照/序列化/写入耗时和大小，不上传诊断。
- 已验证：十章轮换/回旧地图、装备释放与重载、390px截图及事件注入右移；原生方向键自动化仍受暂停影响，待补验。
- alpha.42已发布：核心混合图集拆包，固定预载11张→1张，像素空间估算321MiB→31.5MiB；实际场景还会加载所需模型，不能称游戏总内存31.5MiB。运行时清单18.5MB→5.2MB，完整来源账本保留。十章加载状态、人物和地狱火/群疗截图通过。
- 尚未完成：中低端手机硬件压力测试及原生输入验收缺口。

- 已实现：16MiB音频解码预算，旧章优先回收，正在播放/基础反馈保护，超额诊断；真实浏览器十章预载均在预算内，累计回收107个buffer。

## 阶段2：构筑与节奏（开发中，尚未发布）
- 已实现并本地验收：20分钟停止普通刷怪，最多2分钟决战，HUD倒计时与超时结算原因；旧加时存档迁移获得一次2分钟宽限，后续恢复不重置。
- 已实现并本地验收：正常局2次重修，仅可换已见技能；免费删除且至少保留1项，测试无限换技。已见选项和次数随存档恢复；替换仍从1级/完整冷却开始。
- 已实现并本地验收：两项可配置主修，连续两次缺席后的合法选项保底，三选一主修/配方标记及折叠进度追踪；不送经验/等级，满级及满槽约束保留，存档记录选择与缺席次数。
- 已完成比奇三职业×三种子×三策略27局机制对照，单核成型偏早；见SURVIVOR-FOCUS-REVIEW。尚不作为整体平衡通过。

- 已实现并本地验收：同阶输出/生存/召唤偏好，以及逐部位锁定；保留高阶优先和自动出售，左右戒指独立。偏好/锁定存档兼容，旧模式评分不变。

- 已验证候选：赤月/白野猪预警与攻击后停顿，显示和伤害共用时间定义；新增回血策略18局前后对照及390px截图。近战压力与道士退化仍待定位。
- 已实现候选：阶段首领未击败时跳过下一阶段追加，不积存补刷；最终首领仍按时登场。模拟器补齐可选宝箱拾取与逐分钟输出/召唤物记录，18局对照已完成，不能替代真人验收。
- 未完成：成长/经济/三章实战压力验收，不能把已实现候选等同已平衡；继续定位后两章输出窗口与承伤问题后再发布。

# 章节悬赏：alpha.44候选

目标：提供可拒绝、可理解的额外风险与装备路线，保持连续生存主目标。没有永久属性增长，不降低原敌人属性，不替代原精英/阶段首领。

## 第一组规则

|章节|悬赏|额外目标|
|---|---|---|
|比奇|郊外剿匪|半兽战士精英（orcWarrior）|
|石墓|石墓清道|黑野猪精英|
|白日门|林地猎蛛|月魔蜘蛛精英|

- 游戏时间120≤t<240秒出现“可选悬赏”入口，点开暂停面板说明后明确“接战”。不会走过某点就接战，不会自动暂停；忽略不消耗RNG、不生成敌人、不改变原刷怪节奏。
- 每局一次。生成额外精英，使用原版模型和已有精英调校/危险并发预算；目标出生点距玩家180—280px，合法地面、与玩家连通且有半径12px的直达通路。找不到合适位置或场上敌人已满时拒绝，保持可接取状态并显示原因提示。
- 接取后60秒游戏时间内击杀目标，额外掉落一件本职业可用且外观已登记的二阶武器，保证本职业主攻属性高于开局木剑（不是高于当前装备）。它叠加原精英掉落与击败计数，不是替换原奖励。必须靠近拾取，遵守自动装备比较、锁定和出售规则，不保证替换玩家已有高阶装备。
- 截止时刻本身不算成功。超时失去额外奖励，目标不会凭空消失，仍可按普通精英处理。玩家死亡遵循原结算；暂停不走时钟。
- 目标名称标记“悬赏”，战斗边缘显示剩余秒数，不加指向线。原精英登场提示/声音与血条继续使用。成功与超时留在暂停面板供查看。
- 目标ID、状态和期限随存档恢复，不重置计时。旧存档默认未接取，是否仍在接取窗口取决于实际游戏时间；拒绝引用不存在活体的进行中悬赏。

- 石墓战士176/42/2026未接取对照，与alpha.43原策略的终局时间、承伤、输出、装备、击杀、技能逐项相同。仅支持这三条不接取路径的稳定性，不代表所有地图/构筑无回归。

### 失败路径的进一步观察

种子176比奇战士按原策略做5秒采样（124.7—184.7秒），13个样本目标视线均畅通，距离44—220px，玩家均185HP；目标436.8HP逐步降到92.8HP后超时。可确认目标确实受到伤害，不能把超时写成技能无法释放；样本显示多数时间远于40px近战接近目标，也不足以证明60秒必然不合理。追踪是200秒截断探针，预期以step-limit退出，不计作完整胜负样本；数据alpha44-challenge-trace.log/json，临时探针脚本已移除。

白日门接战后的种子176战士/法师在240秒检查点仍满血；之后的累计赤月范围攻击伤害分别180/118，均是主要压力来源。法师最后由月魔弹幕击杀，不代表月魔贡献最大伤害。这支持把后续首领遭遇与悬赏当场难度分开分析，尚不能推断悬赏导致了这些伤害。保持规则，继续其他种子/路线与真人验证，不以机器人单种子结果普遍削弱敌人。

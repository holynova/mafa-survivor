# 章节悬赏：alpha.44候选

目标：提供可拒绝、可理解的额外风险与装备路线，保持连续生存主目标。没有永久属性增长，不降低原敌人属性，不替代原精英/阶段首领。

## 第一组规则

|章节|悬赏|额外目标|
|---|---|---|
|比奇|郊外剿匪|半兽战士精英（orcWarrior）|
|石墓|石墓清道|黑野猪精英|
|白日门|林地猎蛛|月魔蜘蛛精英|

- 游戏时间120≤t<240秒出现“可选悬赏”入口，点开暂停面板说明后明确“接战”。不会走过某点就接战，不会自动暂停；忽略不消耗RNG、不生成敌人、不改变原刷怪节奏。
- 每局一次。生成额外精英，使用原版模型和已有精英调校/危险并发预算；目标出生点距玩家180—280px，合法地面、与玩家连通且有半径12px的直达通路。找不到合适位置或场上敌人已满时拒绝，保持可接取状态并显示原因提示。
- 接取后60秒游戏时间内击杀目标，额外掉落一件本职业可用且外观已登记的二阶武器。它叠加原精英掉落与击败计数，不是替换原奖励。必须靠近拾取，遵守自动装备比较、锁定和出售规则，不保证替换玩家已有高阶装备。
- 截止时刻本身不算成功。超时失去额外奖励，目标不会凭空消失，仍可按普通精英处理。玩家死亡遵循原结算；暂停不走时钟。
- 目标名称标记“悬赏”，战斗边缘显示剩余秒数，不加指向线。原精英登场提示/声音与血条继续使用。成功与超时留在暂停面板供查看。
- 目标ID、状态和期限随存档恢复，不重置计时。旧存档默认未接取，是否仍在接取窗口取决于实际游戏时间；拒绝引用不存在活体的进行中悬赏。

## 验证与边界

- 三章×三职业在真实地图fixture上验证可达出生、原始模型种类、击杀及合法武器奖励。
- 规则测试覆盖明确接取、忽略不耗随机数、一次奖励、真实拾取换装、超时不删敌、截止瞬间击杀、无合法地面拒绝、存档往返/旧版兼容/无效目标拒绝。
- 石墓战士176/42/2026未接取对照，与alpha.43原策略的终局时间、承伤、输出、装备、击杀、技能逐项相同。仅支持这三条不接取路径的稳定性，不代表所有地图/构筑无回归。
- Ego独立测试局实际按钮接战、规则步进接近、测试击杀掉落、下一步拾取换装通过；截图见QA。测试击杀使用高伤害注入，不伪称60秒真人挑战通过。
- 待完成：自然战斗接战策略、多种子完成率/承伤与收益对照、其他章节事件类型、真人操作反馈。当前单一悬赏模板不能算所有章节事件设计完成。

## 自然成长接战对照（alpha.44候选，2026-11-17）

新增 `--accept-challenge` 可选模拟策略：120秒第一次可接时通过真实暂停/接取API尝试一次，失败不重复刷位置。主动追击实际目标，保留紧急血瓶、可用宝箱、落地装备优先级；不传送、不注入伤害、不赠送技能/装备。未接取前不改变拾取策略。该策略属于测试工具，不替玩家自动接战。

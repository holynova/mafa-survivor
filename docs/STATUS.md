# 开发进度 · 2026-10-27

当前公开版为 **v0.1.0-alpha.5**：道士正常开局与比奇怪物扩充已发布，本地生产版截图已验收；公网交互截图仍因后台浏览器超时待完成。完整 GDD 尚未完成；代码中的章节配置、测试名称和提交标题不作为交付依据。

- Phaser + TypeScript 模拟，React 菜单/HUD，Vite 构建；八方向人物、WASD/方向键、拖动移动、原地图通行与镜头。
- 法师14项、战士6项、道士13项技能已接入；alpha.5 已将道士接入普通模式和短局试玩，不再只在测试菜单中可选。三个职业均有独立普攻，正常单局6槽。
- 道士火符、红绿毒、治疗、双召唤、隐身、增益和困魔规则；装备面板可切换毒素与治疗优先级，显示道术加成和宝宝数量。完整职业平衡仍待验收。
- 升级暂停三选一、技能分支和替换；12×75秒正常局、3×35秒试玩；波间商店、8槽装备、出售/锁定/刷新、掉落拾取和本机战绩。
- 原版木剑开局；27件武器对应19模型、7件衣服对应7模型。人物/怪物/召唤物原动作阴影；树冠保留完整源条带，被遮挡人物显示轮廓。头发、头盔与6件高级外观缺口未解决。
- 原版WAV、静音、首次手势解锁；快速测试可刷怪、装技能、换装、加金币、跳波、无敌、倍速与八方向动作检查；测试局不保存普通战绩、不发结晶。

## alpha.5 已发布增量

- 比奇实际刷怪池为稻草人、多钩猫、钉耙猫、半兽人、半兽战士、毒蜘蛛和半兽勇士，另有骷髅精灵Boss。骷髅、僵尸保留在测试工具和后续矿洞配置中。
- 半兽战士厚血近战，第4波可出现；毒蜘蛛第5波进入普通刷怪池，保持距离并发射可横移躲避的160px/s毒弹。毒弹采用已核验原版施毒动画作幸存者玩法改编，不冒称历史客户端蜘蛛弹体。
- 第4波起每波中段投放一只半兽勇士。直线冲锋先预警0.7秒、锁定预警位置，可侧移躲开；280基础HP不会再次套4倍精英倍率。
- 修复旧敌方弹体使用targetId=-1却只查询敌人导致永不命中的错误。敌弹独立判定玩家/召唤物，先撞到的宝宝可挡弹，不伤敌方同伴；Boss召唤遵守300怪上限。
- 新怪物各自使用源lookID 0x17/0x19/0x18的原版动作和阴影，包含八方向；原版资源共16,509帧、35图集（11初始、24换装按需）。
- 本地191项游戏测试、3项缓存测试通过；人物2,720合成帧、武器5,168帧、怪物2,688帧、阴影4,592帧逐像素对照无差异，28个原WAV校验通过。真实浏览器与线上发布证据另见QA.md。
- 三职业种子176机器人均进入升级与商店后死亡，分别为法师第6波、战士第3波、道士第4波；它们证明固定输入回归可复现，不代表通关率或平衡通过。

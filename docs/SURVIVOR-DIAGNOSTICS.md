# 本地对局诊断（alpha.43候选）

暂停页及结算页的“测试记录与反馈”可下载JSON。数据只在本机保存，不自动发送，没有网络统计服务。它帮助定位成长、承伤及选项问题，不是完整输入录像，也不能凭种子保证重放真人操作。

## 记录内容

- 实际观察区间的等级、HP、有效敌方承伤DPS、击杀、金币获取/消费、敌人数和召唤物数；低于30%生命的步进时长及观察覆盖时长。
- 玩家实际承伤来源增量；击杀回复、吸血、自然回复分别记录。技能及血瓶治疗沿用现有账本，字段明确含友方恢复，不冒充纯玩家回血。
- 三选一曝光和有效选择、技能等级/进化变化、换技前等级、装备替换、补给消费、精英/Boss登场和击杀、致命来源/超时结果。
- 原始renderer回调间隔的最近3600个战斗样本及p50/p95/p99，不使用Phaser平滑delta；暂停期间与恢复后首帧不计入。长任务计数/时长与WebGL丢失/恢复次数属于当前浏览器会话，不宣称是GPU耗时。
- 现有存档写入诊断，包括最近一次快照、序列化和写入耗时。当前未单独统计诊断日志自己的写盘耗时，后续压力测试不能忽略这部分。

区间按实际观察时间形成，通常约一分钟。测试跳时、旧存档从中途接入或恢复间隔不会伪造缺失分钟；导出含startedAt、observedSeconds、resume事件和当前未满分钟区间。DPS分母为游戏时间，不含暂停选项墙钟时间。

## 边界与可靠性

- 正常局只保留最近一局诊断旁路文件，独立于游戏存档；每5秒及状态保存时尝试落盘。读取校验runId、种子、职业、地图、时间与schema；不将诊断写回战斗规则。
- 恢复前缓存旧诊断，再执行会触发存档回调的resume，避免新空段覆盖旧日志的竞态。
- 测试局可导出但不覆盖正常局记录，不进入战绩、进度或奖励。
- 最多1500事件、60个完成区间，超出后记录遗漏计数；持久化UTF-8限制500,000字节。存储失败保留内存导出，不阻塞游戏存档。
- 关键事件记录不会消耗随机数。回归对照确认同种子开关记录不改变实际战斗结果。

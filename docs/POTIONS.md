# 储备血瓶

这是幸存者玩法的有限储药规则。血瓶图标、落地物与治疗动画／音效继续使用已登记的原版资源。

- 普通怪4%、精英15%掉小瓶（20基础HP），首领必掉中瓶（35基础HP）；召唤援军不掉。此次未改掉率。
- 拾取时先按当前缺血使用必要瓶数，满血后最多储存3瓶，剩余瓶数继续留在地面；波末沿用已有清场结算，储备已满的多余瓶不会跨波留在旧地面。
- 生命≤50%自动使用储备；Q／血瓶按钮可提前使用。优先选能满足缺血量的较小瓶，均不能满足时选最大瓶。储备用药共用2秒战斗冷却，暂停不走时。
- 治疗受healing_received影响并截到生命上限，结算只记录实际回复；没有复活效果，非战斗状态不能使用。储存本身不计治疗。
- 新局无储备；储备和剩余冷却随既有波次检查点保存。旧检查点缺字段时默认为空，容量／数值越界拒绝，不凭空发药；战场刷新仍回到既有检查点。

快速测试的「储药与Q回血（沃玛）」实际拾取4瓶并储存3瓶，将地面余瓶放到远处后实际受伤，继续并按Q；「半血自动用药（沃玛）」实际受伤后执行一步自动用药再暂停。两者不保存普通战绩或发放结晶。

# 2026-10-28 原版体验扩充需求

用户明确要求以下九项，全部属于后续开发范围；不能以单个阶段发布代表全部完成。

1. 整体缩短技能冷却，同时降低对应伤害，按持续伤害、爆发、控制与召唤分别对照平衡。
2. 搜索原版客户端UI素材，替换当前网页风格，恢复原版界面构成与视觉。
3. 核对各Boss真实外观，接入更多原版教主、钳虫首领、触龙神等，禁止同模型换名字充数。
4. 扩充有独立原版美术与行为的精英怪。
5. 核对章节实际地形，增加盟重土城、石墓、白日门等不同地貌、章节和对应怪物；不能只换底色。
6. 修复地狱火效果不可见。
7. 神兽攻击应显示原版喷火。
8. 施毒术应让怪物整体显色（红毒／绿毒，用户也提及蓝色旧版表现）；保持攻击、受击、死亡和恢复原色的状态一致。
9. 自动法术采用有限侦测范围，并让侦测距离可以升级。

阶段顺序：先修复技能表现与有限侦测，完成冷却／伤害对照；再完成原版UI与新怪物／新地貌导入。每个实际验收阶段测试、截图、发布。资料优先使用已确认公开分发的mir2x_res固定提交；新增来源需要独立登记。

# 职业起手横向解锁（alpha.45候选）

目标：提供重复开局的新路线，不累积永久生命/伤害，不锁回已开放的地图。只是改变唯一初始技能，原技能池、六槽、技能最高8级和普通成长仍适用。

|职业|默认起手|替换起手|差异|
|---|---|---|---|
|法师|火球术|雷电术|投射清怪与单体定点输出|
|战士|半月弯刀|刺杀剑术|扇形清场与直线穿透；刺杀1级仍要求至少2个目标，2级才允许单目标|
|道士|灵魂火符|召唤骷髅|自身远攻与召唤伙伴/普攻协同|

- 对应职业在普通幸存者局生存至少300秒即可解锁替换起手，胜负不限。暂停和升级不走游戏时钟；测试局与原版模式不计。
- 在现有进度中记录各职业最佳游戏时间roleBest（上限1200），不会因最近20局战绩滚动而丢失。旧进度缺字段默认空；从现存合法战绩按职业补记，不能从仅有章节最佳时间猜测职业，更不能虚构已丢失历史。
- 开局页折叠“起手”面板，使用原版技能图标、明确已选和锁定原因。保持默认开局简洁，不新增下拉框。全地图测试开放标记保持。
- 新局只有1个1级技能、正常初始冷却、相同木剑/基础属性；不是额外赠送第二技能。已见技能随实际起手同步。主修与说明由同一推荐函数提供；骷髅作为起手支援，推荐火符与神兽为后续双主攻，其他起手保留对应攻击组合。主修不等于已学会技能。
- 未解锁选项在界面禁用，开局时重新按当前进度筛选；低层Game.start供内部场景/测试传入本职业受支持的预设，拒绝外国职业/非预设技能并回退默认。没有联网账户或防作弊声明。
- 当前选择在页面内按职业保留，不新增永久自动选中偏好；继续已有存档恢复存档中的完整技能，忽略开局页选择。
- 结算显示该职业已开放的起手入口提示。暂无新角色、图鉴收藏或更多挑战变体，不把第一组替换起手当作所有长期目标完成。

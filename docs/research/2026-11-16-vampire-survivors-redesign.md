# 吸血鬼幸存者研究与玛法幸存者改版建议

研究日期：2026-11-16。项目基线：main cfd47c8965570aacb4cde83978ce25d509afaa8e，alpha.36。本文是研究和设计提案，没有修改游戏或发布版本。

## 证据与范围

对照 Vampire Survivors 的基础单人经典循环；不把所有DLC、特殊角色、无尽、逆转或后期刷金玩法混为统一规则。资料来自可检索的游戏Wiki页面（社区维护），检索结果包含具体属性表；部分原页面直接抓取受robots限制，因此不声称核验了最新版全部源码。此处未实际录制VS整局，也没有新的玩家样本实验。节奏分段是分析，改版指标是待测目标。

本项目以代码为准：src/game.ts、skill-growth.ts、rules.ts、content.ts、classes.ts、cadence.ts、loot.ts、training.ts、builds.ts。STATUS顶端仍是alpha.35，alpha.36主要发布与文档变化，发布记录见CLOUDFLARE.md。既有模拟结果不是人类胜率。

## 一、VS的整体循环

移动、避敌、选择拾取路线→自动武器击杀→收集经验→升级选择武器或被动→杀敌效率上升→更密集敌潮与精英→宝箱强化／进化→构筑成型→限时生存结束→局外解锁→下一局尝试新组合。

操作简化不等于没有策略。主要决策是：集中升级主武器还是先拿稀有配件；为进化保留哪个被动槽；现在绕行拿经验还是撤离；跑去拿地图道具是否值得；某次升级是否使用重掷／跳过／放逐。后期强大是构筑回报，前中期要存在资源和路线压力。

标准经典关卡常以30分钟游戏计时为目标，特殊关卡有更短时间。Hurry使时钟两倍速度并额外增加25%经验收益：30分钟计时约对应15分钟活动游戏时间，菜单、升级和暂停还会延长现实会话；它不等于把全部敌人与武器模拟速度都翻倍。Hyper也不等于Hurry。经典终点的死神机制与后续特殊解法，不应解释为普通新手必须击杀死神才算完成生存目标。[S3]

分析性的30分钟节奏：0—3分钟建立击杀能力；3—10分钟集中主武器并预留进化配件；10—20分钟常见首次进化与战力跃迁；20—30分钟完成互补构筑、承受密集压力并获得清场回报。不是保证在第10分钟进化，每张图、掉落和解锁情况都不同。

## 二、武器、被动和进化

通常最多6种武器和6种被动。常规武器通常8级，常见被动通常5级，存在不同等级上限和地图拾取突破槽位的例外。获得新武器是一次选择，后续同武器选项提升一级；已满级道具退出常规升级候选。满槽使新道具受到限制，强化的方向逐步收敛。角色起始武器、特性、局外解锁和候选权重使每局并非完全自由配置。[S1,S2,S7]

进化一般要求武器满级、拥有指定配件、获得合格宝箱；部分配方需要配件满级或多件物品。不能写成所有被动必须满级，也不能写成任何旧宝箱只要留到10分钟就必定能进化。宝箱资格取决于关卡、掉落来源等规则；经典常见进化窗口在10分钟附近，特殊关卡例外较多。实现时应给宝箱写显式资格而不是只检查开箱时钟。

魔杖是具体可核查的成长样本：[S4]

| 等级 | 新变化 |
|---|---|
| 1 | 最近敌人目标，1发，基础伤害10，冷却1.2秒 |
| 2 | 增加1发 |
| 3 | 冷却减少0.2秒 |
| 4 | 再增加1发 |
| 5 | 基础伤害增加10 |
| 6 | 再增加1发 |
| 7 | 多穿透1名敌人 |
| 8 | 基础伤害再增加10 |

最终4发、30基础伤害、1秒冷却、2个命中目标容量，再配Empty Tome可进化Holy Wand。发射有弹间隔、命中和目标约束，不能把“伤害×发数÷CD”当作实测DPS。忽略这些因素的吞吐代理从10×1/1.2≈8.3到30×4/1≈120，是14.4倍；穿透还提高群体收益。这体现升级形态与数值一起增长，而不是每级只+10%。

Empty Tome共5级，每级冷却减少8个百分点，满级40%。如果孤立地只考虑这一冷却因素，释放频率为1/(1−0.4)≈1.67倍，而不是增加40%；还需考虑具体武器发射周期。[S5]

Arcanas是独立的规则修饰层，不等于普通被动装备。常见30分钟关卡启用后可开局选择，并在11和21分钟出现相关宝箱Boss；不同关卡时点有例外。Limit Break则是普通成长完成后的延伸机制，不适合先拿来解决新手期成长不足。[S6,S1]

## 三、经验、经济和数值原则

VS 1→2级需要5XP，随后到20级前需求通常每级增加10；21—40阶段增量13；41级以后增量16；20和40级另有600／2400经验门槛及临时Growth规则。其意义是早期决策频繁、后期结合大量击杀继续成长，不应孤立照搬这张表而不复制XP掉落与怪潮产量。[S1]

经验与金币功能不同：经验主要建设本局武器／被动，金币主要服务购买和局外成长。VS有商人，可出售特定武器和Golden Eggs，另有特殊规则改变商人内容；所以“VS完全没有商店”是不准确的。但每75秒强制停战购物不是经典主循环。[S8,S9]

数值分析应至少分开：单体有效DPS、群体覆盖、实际命中率、输出可用时间、控制带来的接敌收益、拾取效率、单位时间XP、受伤频率和恢复。伤害数字不能脱离距离、遮挡、穿透与敌人密度比较。增怪同时提供更多经验：这既是压力也是资源；只增加血量更容易造成刮痧和滚雪球中断。

## 四、当前项目的实际差异

| 维度 | 当前玛法幸存者 | 与经典VS循环的差距 |
|---|---|---|
| 单局 | 12×75秒=15分钟活动战斗；另有11次商店与升级停顿；短局3×35秒 | 战斗被固定分段打断 |
| 结束 | 最后一波结束时检查bossKilled；Boss约在最后一波25秒后出生，约剩50秒 | 生存与短时Boss输出门槛耦合 |
| 波末 | 清空敌人、弹体和效果，回收地面经验及部分金币 | 路线、危险和资源可被定期清算 |
| 刷怪 | 基础每波35→408；章节压力除数1—4.2；普通投放在场<300 | 后期章节偏少量硬怪，未形成持续怪潮 |
| 技能 | 33种职业技能，通常6槽；存在战士4槽配置；每技能6级 | 没有明确的满级武器＋配件＋宝箱进化主循环 |
| 满级门槛 | 6级要求第6波起 | 拿齐升级仍可能被波次锁住 |
| 升级候选 | 倾向一个旧技能、一个新技能、属性补足三项；可关注保底 | 不等于VS统一武器／被动抽选池 |
| 装备 | 传奇装备栏、攻魔道防与外观、商店交易 | 未形成6个有限被动槽的配方取舍 |
| 技能书 | 只卖尚未拥有技能；每局最多2本；80/140/220基础价，随波增长 | 可以补构筑，但不是主武器连续升级来源 |
| 经验 | 下一等级12+8L；波末满足击杀条件可补修炼经验 | 成长依赖补偿机制，弱化现场资源路线 |
| 地图 | 固定2208×1536世界，10章原版地貌、碰撞和遮挡 | 对移动、刷怪距离和近战接敌约束较强 |
| 强化上限 | 全局CDR有效上限40%，范围35%等；局部技能加成另算 | 常规强化较克制，缺少进化的机制跃迁 |
| 回血 | 普通怪4%掉20HP瓶、精英15%；Boss35HP；召唤怪不掉 | 已有基础续航，但需随怪潮密度重算 |

具体密度：比奇第1波35/75≈0.47只/秒，第12波408/75≈5.44只/秒。赤月除以4.2后约9和98只/波，即0.12和1.31只/秒（不含额外Boss、召唤等）。高章节因此不一定更有“怪海”感。

火球当前六级：1发→最多2发→威力+12%→CD−8%及弹速+20%→威力+12%→最多3发及CD−7%。局部合计威力+24%、CD−15%，不计其他加成和发射限制的吞吐代理约3×1.24/0.85≈4.38倍。它是有变化的成长，但缺少单独的进化质变。

现有普通模拟90局只有6次通关（法师5，道士1，战士0），定向构筑18局3次法师通关。它们来自已有自动控制器和固定种子，不是玩家胜率；足以提示职业接敌／输出窗口风险，不能据此断言所有玩家只能6.7%通关。

## 五、推荐改版：20分钟连续生存，8级技能＋进化

这是建议产品规格，不是VS官方数字。若目标严格复刻经典时长，改用30分钟并重做整条曲线；网页默认建议20分钟，后续另做10分钟快速和30分钟经典模式，不能只改倒计时。

核心目标：每局形成2个主力进化技能，配1—2个辅助输出和生存／控制；熟练玩家能追求更多进化。追求“定向构筑成功并撑到终局”，而不是每波买贵装备或把所有33技能练满。

### 时间线与成长目标

| 活动时间 | 建议等级（目标范围） | 主要事件 |
|---|---|---|
| 0—1分 | 4—6 | 10—20秒第一次升级；主技能形成清怪能力 |
| 1—3分 | 10—14 | 第一个精英，拿第2—3个技能或关键配件 |
| 3—6分 | 20—26 | 主技能7—8级；第6分钟开放首批进化宝箱 |
| 6—10分 | 32—40 | 第一项进化，安排高产弱怪带来清场回报 |
| 10—15分 | 45—55 | 第二项进化与第二个构筑规则选择 |
| 15—19分 | 58—68 | 完成互补与地图目标，持续提升敌群密度 |
| 19—20分 | 65—75 | 最终围攻；存活到点即普通通关，Boss击杀给额外奖励 |

等级范围用于设计经验供给，不是每分钟硬发等级。升级暂停不计入活动时间，实际会话会更长，需记录菜单耗时。终局Boss若必须击杀，应作为独立挑战模式或明确给予额外决战时间。

### 等级与升级次数预算

6个8级技能从1个初始1级算起，需要47次技能选择：初始技能7次，另5个各8次。6个5级被动需要30次，共77次成长。六个技能全满不应该是普通通关前提。

推荐普通成熟构筑：8/8/6/4/3/1级，技能投入29次；被动5/5/4/3/2/1级投入20次，共49次；进化宝箱另记，不消耗升级选择。若还开放6个8级技能全满与6个5级被动全满，约需77次升级或由普通宝箱补充。必须把非进化宝箱、跳过、属性奖励等纳入预算，避免声称65级就能天然全满。

技能升到8级后仍占原槽；进化替换原技能，通常不额外占槽；配件仍保留。满槽默认不再出现新技能，替换只通过明确事件处理，避免随机升级重复要求丢掉投资。

### 技能、装备和职业

保留传奇人物、武器衣服外观、怪物、地图、声音。建议拆成：6个主动技能槽；6个被动构筑槽；武器／衣服外观及其有限基础属性。需要把现有戒指、项链、手镯与特戒逐一映射，不能让旧装备加成和新被动同名双计。

把33技能重新分工：攻击／召唤保留主动；纯属性强化可转被动；探查类信息能力转基础UI或遗物；隐身、抗拒、困魔等做有明确触发条件的生存／控制。不是把33个原条目全部机械扩成8级。

职业是玩法偏向：战士近身扇扫／环刃／冲击，能够持续移动输出；法师弹体／区域／连锁；道士召唤／毒扩散／续航。第一版保持职业技能池，以每职业至少2套可完成构筑验收；跨职业混搭后续独立平衡。

建议进化配方（均为新设计名称与机制，不冒称传奇原版技能）：

| 基础技能满8级＋配件 | 进化结果 | 可见改变 |
|---|---|---|
| 火球＋火焰戒指 | 爆裂火球 | 命中爆炸与有限穿透 |
| 雷电＋放大范围配件 | 雷霆连锁 | 单点打击转有限跳链 |
| 火墙＋持续配件 | 炼狱火域 | 火区扩散融合，限制重复伤害 |
| 半月＋范围配件 | 环月刀阵 | 正前扇扫转环形连续切割 |
| 烈火＋暴击配件 | 烈焰斩 | 附加下一刀转可贯穿剑气 |
| 火符＋投射物配件 | 灵符阵 | 追踪符配合回旋／穿透 |
| 施毒＋持续配件 | 瘟疫扩散 | 毒怪死亡传播，限制传播深度 |
| 神兽＋召唤配件 | 圣兽 | 持续扇面喷火、可靠接敌和回场 |

第一版配件持有1级即可满足配方，后期高阶配方再要求满级。普通宝箱提供既有技能／被动升级；进化宝箱在配方满足时优先进化；没满足时清楚显示缺什么。建议第6、10、14、17分钟布置合格进化精英，不能只出现一次且错过后永久断构筑。

火球8级建议样例：1级1发；2级2发；3级基础伤害+25%；4级3发；5级冷却−10%；6级增加1次穿透；7级4发；8级基础伤害再+25%及弹速提升。伤害加法累计+50%、冷却0.9倍，吞吐代理约6.67倍，穿透另算；这是候选，不是已平衡方案。进化额外加入爆炸，靠清怪覆盖提升而非再乘一个夸张伤害倍数。

### 商店和经济

取消11次强制波间商店。保留地图商人或少数固定事件，玩家自愿靠近开启；每局限量出售药品、重掷、缺失技能书、定向配件。技能主要靠经验升级，书主要补缺，不卖无限主技能等级、不卖直接进化，否则刷金币会压过战斗构筑。

经验继续可以用用户偏好的大小金币堆画面，但HUD与飘字明确区分经验价值和可消费金币；普通XP堆不能无条件同时给同等数量购买货币。金币与经验的经济曲线分别配置。阶段清场回收移除，增加吸附范围、合堆和低频磁铁，让捡取有策略又不繁琐。

### 怪潮与战斗数值

把每波预算改成按时间、章节、敌群类型配置的投放表。低血杂兵提供杀敌资源；快怪逼位；坦克切路线；远程形成区域危险；精英给宝箱；Boss提供高潮。硬怪不能替换掉所有经验杂兵。

初始测试目标：杂兵TTK早期0.5—1.5秒，成型时0.2—0.8秒；坦克约2—5秒；精英8—20秒；Boss30—60秒。均按同一阶段和基准构筑测有效TTK，不能横比满配法师与裸装战士。满血普通攻击容错约5—8次，连续接触伤害需独立受击窗口；Boss预警可躲且不能长期贴身才能输出。

调参顺序：先确定技能命中覆盖／目标规则与攻击频率，再算有效伤害和敌HP；再配投放数量及XP；最后调整恢复与奖励。用DPS≈单次有效伤害×实际命中数×释放频率×输出可用时间占比作为分析代理，最终以实际日志结算为准。不能沿用“CD乘0.8、伤害也乘0.8”就认为所有技能始终等效：持续区域、召唤、触发和溢出伤害都会偏离。

移除“只要升级就让所有敌人等比例变强”的候选做法，优先时间驱动压力，才能让升级保留优势。局外天赋提供有限便利和解锁，零天赋基准必须可通关，避免用永久加点掩盖局内难度缺陷。

### 地图与性能

先把比奇做成连续生存标杆，再验沃玛的障碍、石墓的窄路。地图上放精英营地、遗物、回血点、定向配件，让移动有目的。不是必须无限地图；现有地图可以扩展可行走区域、处理相机边界和安全出生环，保留原版布局特色。

不直接把怪物上限300改成1000。先测试100/200/300活动敌人，统计更新／绘制／碰撞和分配开销；复用空间哈希、对象池、远处AI降频、掉落合并和特效预算。性能达标后再提高密度。压力不足优先靠投放编队和空间封锁，不靠每帧遍历成倍增加。

## 六、落地顺序与验收

1. 数据基线：记录每30秒等级、击杀、XP产出／拾取、有效DPS、受伤来源、宝箱、技能取得与满级时刻、菜单用时、帧时间。冻结零天赋和固定种子样本。
2. 连续模式：新增明确mode和独立RunDirector；替换波次结束／商店流程，写20分钟时间表、存活胜利和宝箱事件。旧模式暂留回归参考，旧检查点按schema版本处理。
3. 成长模式：独立Weapon/Passive/Recipe/Chest数据与候选池，8级曲线、槽位、满级过滤、重掷／跳过／放逐、条件清晰的进化；删除新模式的第6波锁和波末修炼保底。
4. 垂直切片：先比奇、三职业、每职业2套构筑和少量进化；完成一局的奖励曲线，才扩10张地图与全部技能。
5. 职业与性能：旧自动控制器重写适配连续生存，固定种子A/B比较；不同水平人工试玩，分开报告机器人与玩家结果。
6. 发布：画面／输入／掉落／音频／存档迁移验收后再递增版本和部署子路径；本研究阶段不发布。

建议验收目标（尚未实测）：10—20秒首升；4—6分钟主武器满级；6—8分钟第一次进化；10—13分钟第二次进化；新手死亡能解释原因；熟悉规则的零天赋玩家同地图各职业胜率差距不超过15个百分点。至少每职业30个固定种子离线样本用于异常与分布分析，再配真实试玩；这一样本量不用于精确宣称玩家总体胜率。

必须回归：进化前后技能ID和伤害归因、暂停不推进刷怪、拾取合并不丢价值、满槽候选、已拿配件消失策略、重复开箱幂等、存档旧版迁移、恢复后重复奖励、墙体与召唤接敌、原图人物完整／树冠遮挡／地图边界、D键和移动端操作。技能调整不是素材授权变更，原版来源记录继续保留。

## 结论

建议选择“20分钟连续生存＋8级主技能＋进化＋有限被动槽”，让传奇承担题材、职业和装备辨识度，让VS式连续成长承担节奏。若继续原75秒分波＋商店，则6级依然合理；两种方案不能只换等级数而不重算整个奖励预算。

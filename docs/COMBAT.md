# 战斗规则实现记录

产品基线为 GDD V1.0。职业基础 HP / 速度 / 防御 / 魔御 / 闪避采用 §2.1：法师 100 / 220 / 0 / 2 / 5%，战士 185 / 205 / 5 / 1 / 3%，道士 135 / 215 / 2 / 3 / 5%。三职业均已开放。

## 明确的玩法设计参数

GDD 没有给出以下基础攻击区间与普攻间隔，当前实现采用可调整的幸存者平衡参数，不声称是原版官方数值：

| 参数     | 法师   | 战士   | 道士 |
| -------- | ------ | ------ | --- |
| DC       | 2–4    | 8–12   | 3–5 |
| MC       | 3–7    | 0–1    | 0–1 |
| SC       | 0–1    | 0–1    | 3–7 |
| 准确     | 90     | 90     | 90 |
| 普攻间隔 | 1.2 秒 | 0.9 秒 | 1.2 秒 |
| 普攻距离 | 36 px  | 48 px  | 36 px |

属性由职业基础、装备、被动道具、升级奖励相加后经过软硬上限，再供模拟和面板使用。装备的 DC/MC/SC/DEF/MDEF 区间按草案保留，不再将上下限提前平均。`*_flat` 为两端等量附加，兼容既有强化。

攻击区间用种子随机数掷骰。令 u∈[0,1)，幸运修正后的比例为 u^(0.85^luck)，luck 限于 -10～10；幸运只偏置属性区间，不进入掉率。防御掷骰不使用幸运。命中率为准确加技能准确、减怪物敏捷，限制在基础 55%～100%；基本剑术可提高该下限。敏捷还按每点 0.2% 提升角色闪避，最终闪避不超过 35%。这些系数属于待调参设计值。

现有敌人已区分物理近战、物理箭矢与魔法弹体／Boss技能，召唤物可挡弹；相关回归见forest-enemies、mine-combat、temple-combat与combat-fairness测试。完整属性分布与实战平衡仍待验收。

## 普攻与战士

- 普攻不占槽，即便六槽为空仍可近身挥砍。基本剑术属于占槽常驻被动，没有虚构的零 CD 施法循环。
- 攻杀（2 秒）与烈火（6.5 秒）先蓄力，再共同修饰下一次普攻；这次挥砍只进行一次命中判定、一次 DC 掷骰和一次暴击。失手也消费蓄力，不产生投射物或额外攻击事件。
- 基础普攻伤害为 DC。攻杀额外伤害为 8+0.5×DC，烈火为 24+DC，各自应用分支强化；共同应用物理伤害、全部伤害和暴击倍率。实际伤害按组成比例归属技能，击杀掉落只生成一次。
- 刺杀默认前方 96 px、窄直线至少两个目标才发动；距离分支每次 +48 px。半月默认 70 px、前方 180°，至少两个目标；角度强化最多 230°，不能升级成 360° 旋风。
- 静止时朝最近可攻击目标；移动时保留移动朝向。烈火普攻优先近身 Boss。近战攻击动作有 0.35 秒占用，防止同一帧连续播放多次挥砍。
- 野蛮冲撞默认 180 px，以每 8 px 检查边界和场景碰撞；撞墙停止并承受基础 8 点反作用伤害。该伤害经过防御且至少 1 点，不被闪避或旧受击保护吞掉。Boss、精英和超过等级限制的怪不被推开。
- 自动冲撞仅在 HP<50%、100 px 内至少三名威胁时搜索安全出口；不穿过 Boss，不结束在 Boss 120 px 内。已经贴近 Boss 时可向外撤离。手动操作为点击技能或空格。

防御、魔御与魔法盾仍受总减伤 65%、单次最低伤害 1 点限制。金币收益采用 20% 软上限、40% 硬上限；经验收益采用 25% 软上限、50% 硬上限。

## 当前限制

三职业技能、商店和战绩按职业区分；旧战绩缺少 classId 时显示为法师，不更改原记录。人物已按实际武器／衣服切换原图模型和前后层；6件高级装备模型、头发与头盔仍缺。6 槽与战士 4 槽专项 A/B、三职业对照、正常局多构筑人工通关和 10k 种子平衡均未通过验收。

## 矿洞规则（alpha.8更新）

矿洞沿用GDD的5种普通怪及尸王基础数值。骷髅战士90–180px距离时短冲，预警0.5秒后以4倍自身速度冲0.6秒，冷却6秒；沿锁定位置运动并受墙阻挡。骷髅弓箭手保持约230px距离，射程420px、0.7秒锁点预警、箭速180px/s、冷却2.5秒，箭矢造成物理伤害。洞蛆沿通道追击并周期快冲。

尸王半血进入第二阶段，速度/伤害各乘1.25一次。每20秒召唤至多2僵尸（狂暴不缩短召唤间隔），遵守300怪总上限；靠近时预警1秒后对130px圈内玩家/宝宝造成1.4倍物理伤害，震地冷却9秒（狂暴6秒）。预警圈固定于施放位置，玩家可离开躲避。首次召唤/震地分别在4/5秒就绪；测试工具可将真实AI冷却归零、Boss降至49%HP，测试局不写普通战绩和结晶。

地图寻路共享按目标格缓存的距离场，玩家与宝宝目标各自处理；刷怪选择同一连通区域的地面格，弹道与击退检测中间路径。弹道技能先检查目标视线，不把视觉高度当作通行坐标；无可射目标时每0.15秒重新检查，技能CD不被空耗。

正常通关一次获得3结晶，矿洞正常远征解锁价3结晶；试用入口与测试入口可直接进入。该解锁价替换了尚未对玩家开放的50结晶配置，以一次比奇通关作为首次解锁里程碑。完整通关率、商店经济和多构筑平衡仍需后续专门验收。

## alpha.8 战斗公平性与成长

旧章节远程预警、骷髅精灵跳跃／安全落点、四Boss召唤频率与无奖励援军已统一修正；细节和三职业四场景对照见[SIMULATION.md](SIMULATION.md)。第三章沿用原怪物HP／伤害，通过较少厚血敌人与对应金币面额匹配开局成长。测试模式增加自动走位，手动键盘／拖动优先接管，普通模式不使用自动控制器。


## alpha.9 近战通行

普通挥砍、攻杀／烈火蓄力及半月／刺杀选敌共享源地图直线通行检查；群攻只用可见可达的近敌决定朝向和至少两个目标条件。无有效目标时不消耗攻击冷却／蓄力，绕到门洞后可正常命中。移动时保持移动朝向、半月最大230度、刺杀前向直线和基本伤害均不改。

测试自动走位的战士按近战42px避让普通目标，敌人近身起手时仍避开；原先远程优先75px会令48px普攻永远够不到。该修正只影响测试工具与离线控制器，不接管普通／试玩的人类输入。

快速测试可关闭自然刷怪（波次普通怪和最终Boss投放），场上既有敌人／Boss仍按AI行动，手动生成不受限制。战士隔墙样例只在测试模式生效，保留真实源地形／连通关系和怪物原图；两只骷髅战士固定移动速度为0，用于隔离验证，不代表正常战斗或平衡模拟。

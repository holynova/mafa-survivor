# 战斗规则实现记录

产品基线为 GDD V1.0。职业基础 HP / 速度 / 防御 / 魔御 / 闪避采用 §2.1：法师 100 / 220 / 0 / 2 / 5%，战士 185 / 205 / 5 / 1 / 3%。道士尚未开放。

## 明确的玩法设计参数

GDD 没有给出以下基础攻击区间与普攻间隔，当前实现采用可调整的幸存者平衡参数，不声称是原版官方数值：

| 参数     | 法师   | 战士   |
| -------- | ------ | ------ |
| DC       | 2–4    | 8–12   |
| MC       | 3–7    | 0–1    |
| SC       | 0–1    | 0–1    |
| 准确     | 90     | 90     |
| 普攻间隔 | 1.2 秒 | 0.9 秒 |
| 普攻距离 | 36 px  | 48 px  |

属性由职业基础、装备、被动道具、升级奖励相加后经过软硬上限，再供模拟和面板使用。装备的 DC/MC/SC/DEF/MDEF 区间按草案保留，不再将上下限提前平均。`*_flat` 为两端等量附加，兼容既有强化。

攻击区间用种子随机数掷骰。令 u∈[0,1)，幸运修正后的比例为 u^(0.85^luck)，luck 限于 -10～10；幸运只偏置属性区间，不进入掉率。防御掷骰不使用幸运。命中率为准确加技能准确、减怪物敏捷，限制在基础 55%～100%；基本剑术可提高该下限。敏捷还按每点 0.2% 提升角色闪避，最终闪避不超过 35%。这些系数属于待调参设计值。

现有怪物仍全部造成物理近战伤害；魔御独立结算入口已具备，远程魔法怪与怪物敏捷分布尚待实现。不要由字段存在推断所有属性已完成实战平衡。

## 普攻与战士

- 普攻不占槽，即便六槽为空仍可近身挥砍。基本剑术属于占槽常驻被动，没有虚构的零 CD 施法循环。
- 攻杀（2 秒）与烈火（6.5 秒）先蓄力，再共同修饰下一次普攻；这次挥砍只进行一次命中判定、一次 DC 掷骰和一次暴击。失手也消费蓄力，不产生投射物或额外攻击事件。
- 基础普攻伤害为 DC。攻杀额外伤害为 8+0.5×DC，烈火为 24+DC，各自应用分支强化；共同应用物理伤害、全部伤害和暴击倍率。实际伤害按组成比例归属技能，击杀掉落只生成一次。
- 刺杀默认前方 96 px、窄直线至少两个目标才发动；距离分支每次 +48 px。半月默认 70 px、前方 180°，至少两个目标；角度强化最多 230°，不能升级成 360° 旋风。
- 静止时朝最近可攻击目标；移动时保留移动朝向。烈火普攻优先近身 Boss。近战攻击动作有 0.35 秒占用，防止同一帧连续播放多次挥砍。
- 野蛮冲撞默认 180 px，以每 8 px 检查边界和场景碰撞；撞墙停止并承受基础 8 点反作用伤害。该伤害经过防御且至少 1 点，不被闪避或旧受击保护吞掉。Boss、精英和超过等级限制的怪不被推开。
- 自动冲撞仅在 HP<50%、100 px 内至少三名威胁时搜索安全出口；不穿过 Boss，不结束在 Boss 120 px 内。已经贴近 Boss 时可向外撤离。手动操作为点击技能或空格。

防御、魔御与魔法盾仍受总减伤 65%、单次最低伤害 1 点限制。金币收益采用 20% 软上限、40% 硬上限；经验收益采用 25% 软上限、50% 硬上限。

## 当前限制

两职业技能、商店和战绩按职业区分；旧战绩缺少 classId 时显示为法师，不更改原记录。人物使用固定原始衣服；武器、头发与头盔叠层还未实现。6 槽与战士 4 槽专项 A/B、三职业对照、正常局多构筑人工通关和 10k 种子平衡均未通过验收。

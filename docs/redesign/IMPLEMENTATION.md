# 连续生存改版实施记录 · 2026-11-16

用户已批准全面开发。当前提交是可玩核心阶段，不是全面验收完成或正式发布。

## 当前真实实现

- `?survivor` 独立入口，原版默认入口和线上 alpha.36 保留。
- 手机摇杆、WASD／方向键、暂停、血瓶、瞬息移动触屏按钮。
- 20分钟连续生存，不再75秒清场或强制进商店。
- 三职业接入，33技能可升8级；前6级沿用已验证成长，7/8级已逐技能配置，增加投射物／目标数、召唤数量、范围形状及辅助持续时间等变化；卡片显示实际增量。
- 6技能＋6被动槽；被动最高5级；三选一、每局3次重掷；职业伤害被动不会跨职业出现。
- 9条进化配方；8级技能＋对应被动＋6分钟后出生精英／首领的宝箱；仅一条合格配方时直接进化，多条合格配方时由玩家选择。
- 火球溅射、雷电最多4跳、半月自身范围刀气、烈火刀爆发、火符扩散、神兽喷火扩散。使用现有来源登记特效，不新增伪原版素材。
- 每2分钟精英、每5分钟地图首领；沿用地图原生怪物／精英／首领及AI。
- 十张原版地图接入；现已按跨局生存目标逐章开放，早期版本有实际战绩的章节保留访问；不代表完成逐章平衡。
- 保留原版地面装备／金币／血瓶、人物怪物阴影与音效设置。
- 真实伤害结算、最近20局独立战绩，键 `mafa-survival-records-v1`；不写旧版战绩或发放旧版结晶。

- 保存角色／技能／装备／被动、怪物及其攻击预警／毒状态、召唤物、飞行弹、持续火墙、掉落、宝箱、待选卡片、随机序列与调度时间。恢复先暂停，待选升级仍保留原候选；不重放怪潮，也不重新抽卡。浮字与音效队列不重播。
- JSON版本／字段／资源ID／实体ID验证，拒绝损坏数据；正常结束或主动放弃删除本模式的续局记录。
- 新模式普通怪／精英生命按章节系数归一化，伤害按系数平方根调整，护甲同步调整，经验补偿降低。首领保留不同机制与原生美术；原模式生成函数和基础怪物表不变。
- 调整前种子176十地图三职业30局，5局生还；调整后同种子23局生还。增加种子177后合计60局，45局生还：法师20/20、战士10/20、道士15/20。固定走位机器人和贪心升级策略，不能当作人类胜率或平衡验收通过。

## 第三次实施：跨局目标与战士起手（2026-11-16）

- 独立永久进度键 `mafa-survival-progress-v1`：章节最佳时间、通关标记、已取得进化；不依赖最近20局战绩，历史滚动不会重新锁关。
- 章节路线：比奇→矿洞→沃玛→祖玛→盟重→蜈蚣洞→石阁→石墓→白日门→赤月。比奇存活5分钟解锁矿洞、矿洞8分钟解锁沃玛，其后各前置章节存活10分钟开放下一章。正常局在自动保存、暂停保存、放弃或结算时记录已达到目标；测试模式和旧版不发放进度。旧分支已有战绩的章节保留进入资格，已有续局可以继续。
- 本局仍以20分钟生还、主升两件进化武器为目标；解锁不要求通关，不增加跨局攻击／生命数值。
- 三职业有各自构筑建议；升级卡显示推荐主力、8级和对应配件，配件说明只列本职业相关技能。大厅、暂停与结算显示章节目标。
- 仅新版战士改为半月弯刀起手，提供早期群伤。原版仍是攻杀剑术，旧续局保留已学技能。
- 710项测试通过；十地图×三职业×两种子复测60局，50局生还。战士同策略20局由10局生还升至15局，平均首次升级10.2秒、已进化样本平均首次进化463.7秒；法师20/20、道士15/20与前轮相同。1102次战斗快照验证通过。
- 战士失败仍集中于祖玛、赤月及一个白日门样本，需进一步检查远程压制与狭窄空间走位；机器人成绩不是玩家胜率。
- 390×844浏览器验证：未解锁章节不可选、战士实际以cleave起手、升级卡正确展示半月增量和广域护符配方；截图 `.artifacts/survival-chapter-guidance.png`、`survival-warrior-build-card.png`。升级节点使用测试模式布置，不向永久进度发奖励。

## 第四次实施：九条进化与可选宝箱（2026-11-16）

- 每职业新增一条：火墙＋广域护符→焚天火域；攻杀＋锋锐戒指→开山斩；施毒＋疾风项链→瘟疫毒雾。合计每职业3条，共9条。
- 焚天火域：火墙命中每1.2秒至多一次炎爆，对140px内其他敌人追加该次伤害的100%，最多12目标。复用原版火焰爆裂，新增爆裂层50%透明度，保持人物可辨识。
- 开山斩：攻杀命中产生110px冲击，对其他敌人追加65%物理伤害，并束缚普通怪0.3秒（再受伤解除）；首领／精英免束缚，每1.2秒至多一次。
- 瘟疫毒雾：每秒最多感染120px内、侦测范围内且无遮挡的3只未中毒敌人；60%绿毒伤害、持续4秒；传播毒单独归因且不再传染。红毒仍按原有减防机制运行，可在暂停面板切换。
- 多个配方满足时，宝箱提供进化选择，不能重掷为普通强化；宝箱只消耗一次，选中后暂停展示结果。候选与冷却可以随旧独立存档兼容恢复。
- 暂停中的进化图鉴显示本职业3条路线的技能等级／配件持有／地上合格宝箱；继续按钮移到面板上方，图鉴默认折叠。
- 修复新模式魔法盾7级持续时间加成被旧7秒上限吞掉的问题：7级实际8.2秒，新模式上限9秒；旧版7秒上限不变。
- 718项测试通过，新增炎爆节流及恢复、束缚免疫／受伤解除、有限传播及墙体／侦测限制、多配方选择恢复／防重复、旧存档缺省字段、盾持续时间等验证。
- 比奇／祖玛／赤月×三职业共9局定向构筑模拟（种子176，主动优先新配方，非前轮同策略比较）：8局生还，166次快照验证；新增火墙／攻杀／毒的进化伤害均实际记录。战士祖玛仍有失败，不是最终平衡结论。
- 390×844截图检查图鉴、进化选择／结果，以及三种新增效果。截图使用测试模式布置；不向永久章节进度发奖励。初次火墙截图发现特效遮盖人物，已换为火焰爆裂并降低该新增层不透明度后重拍检查。
- 仍未完成真机性能／发布、全部地图最终平衡、所有技能独立7/8级成长与更多原版宝箱素材。

## 第五次实施：手机视口渲染与被动取舍（2026-11-16）

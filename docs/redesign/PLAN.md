## 第一步：UI方案与原型（当前）

目标：用可点击的界面原型审阅连续生存、升级选择与武器进化的信息和交互。沿用传奇原版素材；轻量HUD让出战场；显示演示数据，不能冒充可玩关卡。

拟覆盖：
1. 开局：三职业、比奇首关、20分钟生存目标、起始技能。
2. 战斗：顶部经验／等级／计时，生命，6主动＋6被动，暂停入口；移除原大底栏和波间商店提示。
3. 升级：三选一，明确当前→下一级变化，区分新技能／升级／被动；主力关注和有限重掷。
4. 进化：条件、配件、宝箱资格、进化前后形态；包含条件未满足状态。
5. 构筑：技能等级、配件、目标配方、缺失条件和装备外观。
6. 结算：存活时间、进化成果、主要伤害、解锁进展与再来一局。

待确认：电脑优先附手机布局，还是手机触屏优先。用户检查原型并明确通过后才能进入第二步。

## 第二步：单关卡小规模Demo（未获进入批准）
